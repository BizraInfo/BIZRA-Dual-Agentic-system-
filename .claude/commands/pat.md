# /pat - Personal Agentic Team Multi-Perspective Analysis

## Activation
When user invokes `/pat [problem]` or needs comprehensive 7-agent perspective.

## 7-Agent Framework

Every solution must address all 7 perspectives to be complete.

### 1. Strategic Visionary
**Focus**: Why and future impact
- Long-term sustainability
- Risk identification
- Growth trajectory
- Ecosystem positioning

**Question**: What is the strategic vision and long-term impact?

### 2. Creative Innovator
**Focus**: What's new and valuable
- Novel approaches
- Out-of-box solutions
- Methodological innovation
- Unique value creation

**Question**: What creative/innovative approaches could enhance this?

### 3. Analytical Optimizer
**Focus**: Metrics and evidence
- Data-driven analysis
- Performance metrics
- Evidence-based decisions
- Quantifiable outcomes

**Question**: What data/metrics support or challenge this approach?

### 4. Implementation Specialist
**Focus**: How-to and execution
- Actionable steps
- Resource allocation
- Dependency management
- Concrete deliverables

**Question**: What are the concrete implementation steps?

### 5. Quality Guardian
**Focus**: What could go wrong
- Quality gates
- Testing strategy
- Compliance checks
- Ihsan enforcement

**Question**: What quality risks exist and how do we mitigate them?

### 6. User Advocate
**Focus**: Who benefits and how
- User needs
- Usability
- Accessibility
- Satisfaction metrics

**Question**: How does this serve the end user's needs?

### 7. Integration Coordinator
**Focus**: How it fits the ecosystem
- System harmony
- Interface design
- Dependency coherence
- Cross-component alignment

**Question**: How does this integrate with the broader system?

```

### 1. Strategic Visionary

### 2. Creative Innovator

**Steps**:

2. [Step 2]
...
**Dependencies**: [Required resources]

### 5. Quality Guardian
**Quality Gates**: [Checkpoints]
**Test Strategy**: [Validation approach]
**Ihsan Score**: [Preliminary assessment]

### 6. User Advocate
**User Needs**: [Requirements addressed]
**Accessibility**: [Inclusive design]
**Experience**: [UX considerations]

### 7. Integration Coordinator
**System Fit**: [Architecture alignment]
**Interfaces**: [Connection points]

[Unified recommendation incorporating all 7 perspectives]
```

## Constraints
- All 7 perspectives MUST be addressed
- No perspective may override another without explicit justification
- Quality Guardian has implicit veto on Ihsan violations
- Integration Coordinator validates final coherence
