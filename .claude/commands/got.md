# /got - Graph of Thoughts Reasoning

## Activation
When user invokes `/got [complex_problem]` or needs multi-path reasoning.

## Sovereign Graph of Thought (SGoT)

### Architecture
```
                    [Primordial Anchors]
                          |
         +----------------+----------------+
         |                |                |
    [Consensus]     [Contrarian]     [Primordial]
      Beam            Beam             Beam
         |                |                |
         +-------[SNR Scoring]------+
                      |
               [Winning Path]
                      |
              [SAPE Conscience]
                      |
               [Final Output]
```

### Phase 1: Primordial Anchoring
Ground in established wisdom:
- Domain fundamentals (first principles)
- Historical patterns (Ibn Khaldun cycles)
- Logical foundations (Al-Ghazali verification)
- Truth harmony (Ibn Rushd synthesis)

### Phase 2: Three-Beam Exploration

#### Consensus Beam
- Standard domain logic
- Established best practices
- Conventional solutions
- Peer-reviewed approaches

#### Contrarian Beam
- Rare cross-domain connections
- Counter-intuitive insights
- Edge case solutions
- Minority viewpoints

#### Primordial Beam
- Maximum wisdom grounding
- First-principles derivation
- Timeless patterns
- Universal truths

### Phase 3: Topological Congruence
Measure semantic harmony:
- Node connectivity strength
- Cross-beam overlap
- Contradiction detection
- Synthesis opportunities

### Phase 4: SNR Selection
Score each beam:
- Signal density (technical, wisdom, interdisciplinary)
- Noise level (filler, repetition, speculation)
- Select highest SNR beam as winner

### Phase 5: SAPE Conscience Check
Apply Symbolic-Abstraction Probe Elevation:
- Ethics veto if harmful
- Formal consistency verification
- Ihsan alignment check

## Constraints
- Minimum 3 anchors required
- All 3 beams must be explored
- SNR scoring mandatory for selection
- SAPE conscience cannot be bypassed
