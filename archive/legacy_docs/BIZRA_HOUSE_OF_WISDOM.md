### 3. Link Knowledge to Domain

```python
from knowledge_graph.schema import GraphNode, NodeType

# Create a new knowledge node (e.g., a mathematical theorem)
theorem_node = GraphNode(
    node_id="theorem:pythagorean",
    node_type=NodeType.CONCEPT,
    properties={
        "name": "Pythagorean Theorem",
        "statement": "a² + b² = c²",
        "field": "geometry",
    },
    labels=["Mathematics", "Theorem", "Geometry"],
)

# Link to domain
relationship = house.link_knowledge_to_domain(theorem_node, "math_geometry")

# Now you can trace: Pythagorean Theorem → Geometry → Mathematics → Human Knowledge → Quran
```
